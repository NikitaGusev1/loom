# Implement DAG

Use Codex's weight-aware worker defaults: `gpt-5.6-terra` for standard/trivial tasks and `gpt-5.6-sol` for heavy tasks. An explicit `--model` overrides both.

Run the `dag-executor` CLI against a decomposition file.

## Artifact Repository

Before locating a DAG, load `../../references/artifact-repository.md`. Prefer central decompositions under `projects/<project-slug>/decompositions/`.

## Workflow

1. Locate the DAG path:
   - use the explicit argument when provided;
   - otherwise read `decomposition_path` from the selected plan;
   - otherwise find the newest central `projects/<project-slug>/decompositions/decomposition-*.json`, then fall back to `.claude/ai/decomposition-*.json`, and confirm.
2. Inspect repo guidance for expected verification commands.
3. Run the appropriate command from the repo root, typically:

```sh
dag-executor <dag-path>
```

4. If the CLI is unavailable, run `npm run build` in this repo if needed, then use the local executable documented in `README.md`.
5. Monitor events and summarize completed, failed, blocked, and skipped tasks.
6. Never delete worktrees, reset branches, or discard changes unless the user explicitly asks.

For quota, dependency, or verification failures, preserve the event/state files and report the exact resume command.
